# LessonOne

Приложение .NET MAUI: регистрация и вход, список пользователей и редактирование
профиля, просмотр проектов и отделов, редактирование названия отдела.
После входа разделы Departments и Projects доступны на странице Users.

Данные хранятся в SQLite (`app.db`) в каталоге данных приложения. При первом
запуске старая база из рабочего каталога или каталога приложения переносится
с сохранением данных. Недостающие таблицы отделов и проектов создаются
автоматически; тестовые записи при запуске не добавляются.

Для разработки нужны .NET SDK и рабочие нагрузки MAUI для целевой платформы.
Целевые платформы проекта: Android, iOS, Mac Catalyst и Windows.
Сборка Windows из PowerShell:

```powershell
dotnet build LessonOne/LessonOne.csproj -f net9.0-windows10.0.19041.0 -p:TargetFrameworks=net9.0-windows10.0.19041.0
```
